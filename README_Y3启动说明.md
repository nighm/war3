# Y3编辑器快速启动说明

## 🚀 快速启动

### 方法1：使用项目脚本（推荐）
```bash
# 在项目根目录运行
python quick_start.py launch_y3
```

### 方法2：使用批处理文件
双击 `启动Y3编辑器.bat` 文件

### 方法3：直接运行
直接运行 `D:\Program Files\y3\games\2.0\game\Editor.exe`

## 📝 创建新地图步骤

1. **启动Y3编辑器**
2. **创建新项目**：文件 → 新建项目 → 选择"空白项目"
3. **设置项目信息**：名称、路径、作者等
4. **开始编辑**：地形、单位、触发器

## 📚 详细教程

查看 `docs/Y3编辑器新手创建地图教程.md` 获取完整的使用指南。

## ⚠️ 注意事项

- 确保Y3编辑器路径正确：`D:\Program Files\y3\games\2.0\game\Editor.exe`
- 首次使用建议选择"空白项目"模板
- 定期保存项目文件

## 🔧 项目集成

本项目已集成Y3编辑器支持，运行 `python quick_start.py` 可完成完整的环境配置。
