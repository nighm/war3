# Y3编辑器新手创建地图教程

## 概述
Y3编辑器是一个现代化的魔兽争霸3地图编辑器，提供了直观的界面和强大的功能。本教程将指导您从零开始创建一个干净的新地图项目。

## 启动Y3编辑器

### 方法1：使用项目脚本（推荐）
```bash
# 在项目根目录运行
python quick_start.py launch_y3
```

### 方法2：使用批处理文件
双击 `启动Y3编辑器.bat` 文件

### 方法3：直接运行
直接运行 `D:\Program Files\y3\games\2.0\game\Editor.exe`

## 创建新地图项目

### 第一步：启动编辑器
1. 运行Y3编辑器
2. 等待编辑器完全加载
3. 熟悉界面布局

### 第二步：创建新项目
1. 点击菜单栏的 **"文件"** → **"新建项目"**
2. 在弹出的对话框中选择 **"空白项目"**
3. 设置项目名称（建议使用英文，如：`MyFirstMap`）
4. 选择项目保存路径（建议保存在项目的 `maps/` 目录下）
5. 点击 **"创建"** 按钮

### 第三步：配置项目设置
1. 在项目设置中配置：
   - 地图名称：你的地图名称
   - 作者：你的名字
   - 描述：地图的简要描述
   - 玩家数量：建议从2-4人开始

### 第四步：基础地形编辑
1. **地形工具**：
   - 使用地形笔刷工具绘制地形
   - 选择合适的地形类型（草地、森林、山地等）
   - 调整地形高度创建起伏

2. **水域添加**：
   - 使用水域工具添加河流或湖泊
   - 调整水域深度和透明度

### 第五步：添加基础单位
1. **玩家起始点**：
   - 为每个玩家放置主基地
   - 设置起始资源（金矿、木材等）

2. **中立单位**：
   - 添加野怪和资源点
   - 设置单位属性和行为

### 第六步：基础触发器设置
1. **游戏初始化**：
   - 设置游戏开始时的初始状态
   - 配置玩家资源和单位

2. **胜利条件**：
   - 设置游戏胜利和失败条件
   - 配置计分系统

## 常见问题

### Q: 如何保存项目？
A: 使用 Ctrl+S 或菜单 "文件" → "保存项目"

### Q: 如何测试地图？
A: 在编辑器中点击 "测试" 按钮，或使用快捷键

### Q: 如何添加自定义单位？
A: 在对象编辑器中创建新单位，设置属性和模型

### Q: 如何调试触发器？
A: 使用Y3编辑器的调试工具和日志输出
