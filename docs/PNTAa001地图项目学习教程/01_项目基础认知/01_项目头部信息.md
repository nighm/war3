# 项目头部信息详解

## 📋 文件概述

**文件位置**: `maps/PNTAa001/header.project`  
**文件类型**: 项目级配置文件  
**作用**: 定义整个地图项目的基本信息和全局配置

## 📊 配置项详解

### 1. **时间戳配置**

#### `create_stamp`
- **值**: `"202306120000"`
- **含义**: 项目创建时间
- **格式**: `YYYYMMDDHHMM` (年月日时分)
- **实际时间**: 2023年6月12日 00:00

#### `editor_stamp`
- **值**: `"202306120000"`
- **含义**: 编辑器最后修改时间
- **作用**: 记录项目在编辑器中的最后操作时间

**学习要点**:
- 时间戳格式统一，便于程序处理
- 创建时间和编辑器时间相同，说明项目刚创建

### 2. **加密配置**

#### `encrypt_sections`
```json
"encrypt_sections": [
    "archive_data",           // 存档数据
    "global_archive_data",    // 全局存档数据
    "archive_table_data"      // 存档表格数据
]
```

**加密内容**:
- **archive_data**: 玩家存档数据，包含游戏进度
- **global_archive_data**: 全局存档数据，可能包含服务器数据
- **archive_table_data**: 存档表格数据，存档的元数据

**学习要点**:
- 敏感数据需要加密保护
- 存档数据是加密的重点
- 体现了数据安全的设计理念

### 3. **地图配置**

#### `entry_map` (入口地图)
```json
"entry_map": {
    "id": 293680396310147901956047313112794851761, 
    "name": "EntryMap"
}
```

**配置说明**:
- **id**: 地图的唯一标识符（长整型）
- **name**: 地图名称，EntryMap表示入口地图

**学习要点**:
- 每个地图都有唯一的ID
- 入口地图是玩家进入游戏的第一个地图
- ID使用长整型确保唯一性

#### `lobby_map` (大厅地图)
```json
"lobby_map": {
    "id": "", 
    "name": ""
}
```

**配置说明**:
- **id**: 大厅地图ID（空值表示无大厅）
- **name**: 大厅地图名称（空值表示无大厅）

**学习要点**:
- 大厅地图是可选的
- 空值表示直接进入游戏，无大厅等待
- 适合单人游戏或快速开始

### 4. **物理系统配置**

#### `phy_mode`
- **值**: `"2.5d"`
- **含义**: 物理模式设置

**物理模式说明**:
- **2D**: 完全2D，只有X和Y轴
- **2.5D**: 2.5维，有X、Y轴和有限的Z轴
- **3D**: 完全3D，有X、Y、Z三个轴

**2.5D的特点**:
- 地形有高度差异
- 单位可以上下移动
- 但Z轴移动有限制
- 平衡了性能和视觉效果

### 5. **项目标识配置**

#### `project_id`
- **值**: `292548501185683801640613621410766186929`
- **含义**: 项目的全局唯一标识符

**ID系统设计**:
- 使用长整型确保唯一性
- 可能包含时间戳、随机数等信息
- 便于在多个服务器间同步

#### `project_name`
- **值**: `"PNTAa001"`
- **含义**: 项目名称

**命名规则分析**:
- 可能遵循特定的命名规范
- 便于项目管理和识别

#### `version`
- **值**: `17`
- **含义**: 项目版本号

**版本管理**:
- 从1开始递增
- 当前是第17个版本
- 说明项目经过多次迭代和优化
